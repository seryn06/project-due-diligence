## 三、skill 独有发现（v1.2 不知道、且直接关系方案）

**第一轮**：
1. **Dissecting Agentic RAG（P297，2026）**：agentic RAG 组件消融受控先例——相关工作必补；B+ 臂表述收窄为"先例均为通用场景/非同证据设计"。
2. **Illusion of Agentic Complexity（P302，2026）**：架构复杂度收益被高估——支持六臂动机，警示"多智能体优越"叙事不能预设。
3. **BenchAgent / Do More Agents Help（P220，2026）**：3,302 实例配置受控单 vs 多——方法论最接近的先例。
4. **判官统计校准（P237，2026）**：判官分数直接统计假阳性膨胀——T9 必要性有文献支撑。
5. **MAST（P120）+ MAST-Data**：失败分类学 1600+ 轨迹，v1.2 未引。
6. 污染线（P112/P254 等）：为 manifest 快照锚定提供文献正当性。

**第二轮（扩 Q7/Q8 后新增）**：
7. **AgentRewardBench（P357，2025）**：把"轨迹自动评测器"本身作为评测对象——T7 必须先做评测器校准（轨迹判定 vs 人工一致率）再上量，v1.2 的 T7 无此环节。
8. **TRAJECT-Bench（P384）/ 双平面框架（P385，执行保真 vs 行为正确）**：T7 五指标的组织框架直接可借；"轨迹≠预设路径"原则有了操作化先例。
9. **XHotpotQA（P388，2026）**：整例翻译型多语基准掩盖语言边界失败——为 v1.2 弃双语 twin、全英文主集的决策提供直接文献证据（该决策原是工程直觉）。
10. **回归/监控簇（P328 API 静默回归 + P377 离在线背离 + P322 传统监控盲区）**：T12 回归闭环从"可选项"升级为有证据支撑的必要项——LLM API 静默更新回归是真实风险。
11. **τ-bench（P392）**：领域规则遵循+人交互是既有工具基准不测的维度——v1.2 "不同构仅引用"的判断成立且有据可引。

## 五、创新审计结论（三分法）

- D1（同证据协作净增益）：4 子主张中 2 条**已覆盖**（组件消融 P297、单 vs 多质疑 P302）、1 条**可能差异待核验**（同证据单次生成对照 + 修复切片 + 领域场景组合）、1 条**证据不支持**（"不加对照宣称多智能体优越"）→ v1.2 的贡献定位需按此收窄表述。

## 七、v0.1 验收结论

**可用性判定：通过。** 七门全绿、无豁免；报告 11 章完整且全部主张可溯源；对照人工方案，核心缺口全部独立复现（6/6），并贡献 6 项 v1.2 未知的关键文献/证据——其中两个最近先例（P297/P302）直接影响论文相关工作写法。

**遗留改进项**（按影响排序，含第二轮教训）：
1. **P0 级——问题树构建的"蓝本全覆盖"检查**：本轮最大教训是问题树压缩了用户蓝本的一等内容（轨迹/回归监控两维）导致整簇漏检。改进：P1 出口前增加"输入文档逐节对照"步骤（SKILL.md 已可加一行：若用户提供蓝本/方案文档，问题树必须逐节映射其维度，未映射维度需说明理由），并把"蓝本显式引用清单回查"纳入检索矩阵（通用 benchmark 簇漏检的同源问题）；
2. 专有名词基准（τ-bench 类）泛查召回不可靠——协议模板加"题名精确检索"标准步骤；
3. L2/L3 精读的全文获取未启用（scansci-pdf 集成是 P4 的"有则用"路径，本次未触发）——方法细节级对比当前靠摘要，证据等级受限；
4. S2 持续限速下，OpenAlex refs-of/cited-by 已兜底，但建议 protocol 支持"引用扩展种子"作为一等公民查询类型（当前用 cites: 前缀 hack 进 query 字段）；
5. 英文模板 experimental 未验证（G7 针对 zh 章节标题）；
6. 证据编号在"先写卡片后补账"时发生错位（本轮 G7.3 抓住后修复）——可让 render 顺带校验卡片引用号与台账一致性。
