# 范例：生物领域运行（格式示范——内容为教学示例，非真实文献数据）

> 目的：证明同一套流程在非 AI 领域完全适用。以下是一个"植物次生代谢通路基因功能研究"
> 立项背调的三个关键产物的示范写法。注意与 AI 领域范例（example_paper_note.md 等）对比：
> 流程、台账结构、gate 规则完全相同，只有数据源组合和卡片字段按领域调整
> （见 references/domain-adaptation.md）。

## 一、问题树（节选）

```
- Q1 现状：目标次生代谢通路的酶学组成与关键基因 — 理由：确定研究的通路边界与已知基因清单
- Q2 证据：各关键酶的体内功能验证证据等级（体外酶活/瞬时转化/稳定遗传/突变体互补各有多少）— 理由：证据等级决定哪些"已知"实际未经充分验证
- Q3 物种：功能验证的物种覆盖与模式物种外推风险 — 理由：单物种结论跨物种外推是本领域最常见错误
- Q4 调控：通路的转录调控与环境响应证据 — 理由：应用方向（代谢工程/品质改良）依赖调控知识
- Q5 空白：通路中哪些步骤无基因-level 证据、哪些物种完全未覆盖 — 理由：直接决定可做的题目
```

## 二、精读卡片（示范一张）

```
# P023 精读卡片

> 某物种 DODA 同源基因功能研究 (2021) | venue: 某植物学期刊 | 挂节点: Q2,Q3 | access: 全文可读

## 任务定义
验证某物种中 DODA 同源基因在甜菜素合成中的功能（此前该物种甜菜素含量报道为零）。

## 方法
同源克隆 + 大肠杆菌体外酶活测定 + 本氏烟草瞬时转化显色实验 + 稳定转化株系表型分析。

## 数据集
物种：目标物种（基因组注释版本 v2.1）；材料：花瓣（开花 D1/D3 两个发育阶段）；
对照：已报道 DODA 功能的参考物种序列。← 生物领域必须记录项见 domain-adaptation.md

## 基线
参考物种已验证的 DODA 蛋白序列与酶活参数。

## 指标
体外酶活（产物转化率 μmol/min/mg）；转基因株系靶色素含量（mg/g FW）。

## 结果
体外酶活检出但低于参考蛋白 42%；瞬时转化显色阳性；稳定转化株系靶色素含量提升 3.1 倍（n=8 株系，p<0.05）。

## 局限
单一物种单一基因型；未做突变体互补（该物种遗传体系不成熟）；酶活差异未排除蛋白表达量因素。

## 证据引文
"stable transformants accumulated 3.1-fold more target pigment than empty-vector controls"
（Results §3）→ evidence.json E12
```

```json
  "question_id": "Q2",
  "gap_type": "方法",
  "supporting_evidence": ["E05", "E09"],
  "counter_evidence": ["E11"],
  "existing_solutions": "E11 在近缘物种做了瞬时转化显色，但未定位到具体同源基因，不算基因级验证",
  "research_question": "该步骤的候选基因在体内是否承担相同功能？",
  "validation_plan": "目标物种稳定转化 + 酶活缺失突变体互补；两个独立基因型重复",
  "status": "待验证"
}
```

注意：`counter_evidence` 在这里列了一条"部分解决"的工作并说明为什么不算解决——
生物领域大量缺口处于这种"有相关证据但证据等级不足"状态，缺口条目要把等级差写清楚，
而不是简单说"没人做过"。
