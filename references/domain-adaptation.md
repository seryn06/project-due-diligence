# 领域适配指南（P2 建协议时按本领域加载对应小节）

本 skill 的流程（七阶段、五条检索线、三台账、质量门）与领域无关。需要按领域调整的只有三处：
**数据源组合、检索词写法、精读卡片必须记录的字段**。下表按领域给出默认配置。

## 数据源优先级

| 领域 | 主源 | 补充源 | 说明 |
|---|---|---|---|
| 生命科学/农学/生物 | OpenAlex + **Europe PMC（必用）** | arXiv（仅定量方法类） | 物种拉丁名检索；EPMC 有开放全文 |
| AI/计算机 | OpenAlex + arXiv（必用） | EPMC（仅生物医学应用类） | arXiv 限速严格（1 次/3 秒，频繁 429），失败换 OpenAlex 同义查询 |
| 医学 | EPMC + OpenAlex | — | 报告规范文献（CONSORT/PRISMA/EQUATOR 系）单列一条检索线 |
| 社会科学 | OpenAlex | EPMC（交叉学科） | 检索词注意学科间同义术语差异 |
| 工程/材料/化学 | OpenAlex + Crossref 元数据 | 专利库不在本 skill 范围内，报告中说明 | 会议文献覆盖不全需声明 |

## 检索词写法

- **生命科学**：物种拉丁名与通用词双轨检索（如 `Anthocyanin biosynthesis` 与 `flavonoid pathway`）；基因符号有歧义（同一符号在不同物种指不同基因），检索式加物种限定词。
- **AI/计算机**：专有名词基准/工具名（AgentBench、τ-bench 这类）必须用精确题名检索，概念词组合检索对专有名词不可靠；缩写与全称各检索一次。
- **医学**：干预/人群/结局三要素分别组词（PICO 结构）；MeSH 主题词与自由词并用。
- **社会科学**：同一概念在不同学派名称不同，同义词组从 3 个起步扩展到 5-6 个。

## 精读卡片必须记录的字段（在八段模板的数据集段内）

| 领域 | 必须记录 | 原因 |
|---|---|---|
| 生命科学 | 物种、基因型/品种、**基因注释版本**（如 TAIR11 与 Araport11 结论不可直接比较）、实验材料（组织/发育阶段）、实验类型（体外酶活/瞬时转化/稳定遗传/突变体互补） | 跨物种/跨版本结论不可直接迁移，这是生物领域最常见的外推错误 |
| AI/计算机 | 模型与版本、预算设置（token/调用数）、随机种子处理、基准版本与快照 | 复现依赖这些参数；API 披露的用量可能不准确 |
| 医学 | 研究设计（RCT/队列/病例对照）、样本量与人群、结局定义、伦理批件号（如文中给出） | 证据等级由设计决定 |
| 社会科学 | 抽样方式与样本构成、测量工具（量表名称与版本）、效应量与置信区间 | 可比性由测量工具决定 |
| 工程/材料 | 材料体系与规格、表征方法与仪器参数、测试条件（温度/载荷/气氛） | 条件不同性能数字不可比 |

## 领域差异对报告的影响

- 已证实问题的标准：各领域"多篇独立印证"的门槛相同，但生物领域要注意**同一实验室的系列论文算单一来源**；
- 反证线在生物领域同样必要：查"已解决/已有替代解释"（例：某表型后来被归因于另一条通路）；
- 综述密集的领域（医学/生物）综述线配额容易满足；新兴领域综述少，用题名含 survey/review 的会议教程与预印本综述补，不足时按规则豁免并披露；
- 领域术语的双语问题：中文项目检索英文文献，报告用中文撰写时术语首次出现给出英文原文。
